# 📊 Dashboard Interativo de Salários com Python

Projeto prático desenvolvido em Python durante a Imersão de Dados com Python (Alura), com foco na construção de um dashboard interativo para análise de salários nas áreas de dados.

O projeto utiliza Pandas para manipulação e tratamento dos dados, Seaborn e Matplotlib para a criação das visualizações e Streamlit para o desenvolvimento da interface interativa. A aplicação demonstra na prática, automação de análise de dados, visualização e deploy de aplicações Python, com publicação em ambiente web.

🔧 Tecnologias utilizadas

Python

Pandas

Seaborn

Matplotlib

Streamlit

📊 Funcionalidade

Dashboard interativo para análise salarial nas áreas de dados
